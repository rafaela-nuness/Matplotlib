# Gráfico de Vendas com Matplotlib

Projeto em Python para criar um gráfico de barras que representa as vendas de cada dia da semana, utilizando a biblioteca Matplotlib.

## Funcionalidades

* Exibição das vendas de segunda-feira a domingo.
* Criação de um gráfico de barras.
* Personalização do título e dos eixos.
* Visualização dos dados em uma janela gráfica.

## Tecnologias utilizadas

* Python
* Matplotlib

## Instalação

Instale a biblioteca Matplotlib:

```bash
python -m pip install matplotlib
```

## Como executar

No terminal, execute:

```bash
python grafico.py
```

## Dados apresentados

O gráfico utiliza valores de vendas fictícios para representar o desempenho ao longo da semana.

## Objetivo

Praticar a criação e a personalização de gráficos em Python, utilizando o Matplotlib para transformar dados em representações visuais.
